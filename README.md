## Abstract

NEXUS AI is an intelligent enterprise knowledge management platform designed to help users retrieve accurate information from large collections of documents using Generative AI and Retrieval-Augmented Generation (RAG).

The platform aims to process documents, perform semantic and keyword-based retrieval, and generate context-aware responses supported by relevant source citations. It will incorporate advanced retrieval techniques, security mechanisms against prompt injection, and automated evaluation to assess the reliability and quality of generated responses.

The project aims to demonstrate a production-oriented, locally deployable GenAI application using open-source technologies.

## Planned Technology Stack

- **Programming Language:** Python
- **Backend:** FastAPI
- **Frontend:** React and TypeScript
- **Database:** PostgreSQL with pgvector
- **LLM Runtime:** Ollama
- **Embeddings:** Sentence Transformers
- **Retrieval:** BM25 and Vector Search
- **Containerization:** Docker
- **Version Control:** Git and GitHub
